# Manual QA Internship — Social Media Manager

## Project Overview

A web-based social media management and automation application tested during my QA internship.

The application enables users to gather and analyze social media profile information, including followers, following, posts, reels, and other content across multiple platforms. It also provides functionality for managing connected accounts, scheduling content, and publishing posts across different social media platforms.

My role involved independently performing manual testing to validate application functionality, user workflows, UI consistency, and responsive behavior while identifying and reporting defects during the development phase.

**Project Type:** Web Application  
**Domain:** Social Media Management and Automation  
**Role:** Manual QA Intern  
**Testing Approach:** Independent Manual Testing

---

## Responsibilities

- Performed functional testing to validate application features and expected behavior.
- Conducted UI testing to identify visual inconsistencies, alignment issues, and usability defects.
- Executed responsive testing across different screen sizes and viewport dimensions.
- Independently tested end-to-end user flows across interconnected application modules.
- Performed exploratory testing to identify unexpected behavior and edge cases.
- Identified, reproduced, and reported functional, UI, and responsive defects.
- Documented defects with reproduction steps, expected results, and actual results.
- Assigned defect priorities based on impact.
- Performed retesting to verify defect fixes.
- Conducted regression-oriented testing on related functionalities.
- Independently explored application modules in the absence of formal requirement documentation.

## Testing Methodology

Followed a practical manual QA workflow:

1. Explored application modules and understood their functionality.
2. Identified important user journeys and testing scenarios.
3. Executed functional, UI, responsive, and exploratory testing.
4. Reproduced and investigated identified defects.
5. Reported issues with clear descriptions and supporting evidence through internal processes.
6. Retested resolved defects.
7. Performed regression-oriented checks on related functionalities.
